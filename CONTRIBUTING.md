# Contributing to Reporting Agent

We welcome contributions! Please follow these guidelines to keep the project clean and professional.

## Reporting Issues
If you encounter any issues, please report them with:
- A clear description of the problem.
- Steps to reproduce the issue.
- Expected vs actual behavior.

## Pull Requests
1. **Branching**: Use descriptive branch names (e.g., `feat/add-new-tool`, `fix/scrolling-issue`).
2. **Code Style**: 
   - Maintain existing coding style (PEP8 for Python, standard TS/JS for frontend).
   - Ensure your code is linted and formatted before submitting.
3. **Documentation**: If your change adds a feature, please update `README.md` or `RUNNING_LOCALLY.md` accordingly.

Thank you for helping improve the Reporting Agent!
